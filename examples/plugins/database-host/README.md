# 通过已有服务器连接数据库

此示例演示普通插件通过 Netcatty 保存的 SSH 服务器连接 MariaDB，并执行查询、新增、修改和删除。Vault 页面和终端侧栏都可打开它。

1. 构建插件：`node examples/plugins/database-host/build.mjs`，将 `.package` 打包为 `.ncpkg` 后安装。
2. 输入数据库地址、端口、库名和数据库账号。数据库在 SSH 服务器本机时使用 `tcp://127.0.0.1:3306`。
3. 点击“选择服务器并连接”，在宿主中选择一个 SSH 主机，再确认目的地址。SSH 登录信息由 Netcatty 使用，插件不会收到密码或私钥。
4. 输入 SQL，点击“确认并执行 SQL”，确认后查看结果。每次响应最多 64 KiB、500 行、32 列；页面预览最多 7500 个字符，请自行加 LIMIT。超过上限会关闭连接，避免无界读取。
5. 使用结束后断开。修改语句不会自动重试；如果执行中断，请先检查数据库是否已经完成修改。

数据库密码只用于当前连接，输入框在提交后清空，不持久保存。数据库账号决定可操作的表和权限；只读账号不能通过这个示例绕过数据库的限制。

这是开发示例，不是完整驱动：只支持 MariaDB/MySQL 4.1 协议的 `mysql_native_password`，不支持 MySQL 8 的 `caching_sha2_password`、PostgreSQL、二进制参数绑定、协议内 TLS、连接池或数据库密码保存。SSH 加密覆盖到所选 SSH 服务器；如果数据库位于另一台机器，后续 TCP 路段不会因此自动获得数据库 TLS。每个插件实例只持有一条示例连接，两个入口共用它；关闭页面会断开连接。

平台连接能力与数据库协议独立。其他数据库插件可以实现各自的浏览器驱动；数据库业务逻辑不需要加入 Netcatty。

完整授权、限额和调用方法见 [宿主连接说明](../../../docs/plugin-platform/host-byte-streams.md)。
