# Directory Picker：目录显示与切换

日期：2026-10-29。状态：功能规格草案。总体目标与架构影响见 [README](README.md)。

参考行为：Warp 的目录芯片显示当前路径，点击打开搜索、父目录和直接子目录菜单；贡献者亲自操作确认，单击子目录会立即切换并关闭菜单。匹配算法、隐藏目录默认策略、父目录关闭行为与错误恢复仍未逐项验证；下文为 Netcatty 拟采用的明确规则。

本地模拟见 [directory-picker-demo.html](directory-picker-demo.html)，不访问文件系统或真实终端。

## 1. 目标与首期边界

用户在撰写命令前，能看到**当前聚焦终端的真实工作目录**，并通过一个小菜单搜索当前层子目录、返回父目录、选择目录，使接下来执行的命令落在目标位置。

本期包含：目录芯片、当前 cwd 同步、弹出菜单、当前层搜索、父目录、直接子目录与目录符号链接、内部滚动、定向 cd、成功确认、键盘操作、错误恢复、草稿保护、会话隔离。

本期不包含：文件操作、文件预览、目录创建、全盘或递归搜索、历史目录、书签、路径自由输入、在菜单内下钻后单独确认、修改新会话默认目录、其他芯片功能。

范围建议：优先 macOS/Linux 本地 POSIX shell。SSH POSIX 是同一产品能力的目标场景，但是否同批上线应由就绪状态、cwd 可信度与连接能力共同决定；不得为了演示远程功能而在远程菜单中列举本地目录。Windows PowerShell/CMD、WSL、mosh/ET、跳板单通道、串口和网络设备的支持以能力探测为准，不能无条件套用 POSIX 命令。

## 2. 外观

目录芯片使用文件夹图标与路径，长路径保留尾部目录名，悬停显示完整路径。菜单锚定芯片上方、左对齐，间隔约 6–8px；宽约 360 CSS px，受窗口可用宽度约束。搜索行高约 34–36px，目录行约 30–32px，列表内部滚动。背景、文字及活动项沿用终端主题和应用 accent。

## 3. 信息模型与显示规则

必须分别保存三个概念：

| 值 | 含义 | 可否作为当前目录显示 |
| --- | --- | --- |
| confirmedCwd | 该会话最新可信 cwd 回报 | 可以 |
| listingBase | 本次菜单读取目录列表所依据的绝对路径 | 菜单上下文；不自动改变芯片 |
| pendingTarget | 用户已选择、尚未确认成功的路径 | 只能作为“切换中”提示 |

目录 chip：已知用户 home 时，可将 home 的完整路径前缀缩为 `~`；必须按目录边界比较，不能把 `/home/alice2` 错缩成 alice 的 home。远程 home 来自远程身份，不能使用应用本机 home。

显示绝对路径与命令参数是不同层次。`~/git` 只是显示，执行时应优先使用从目标会话／文件系统得到的绝对路径，不把 UI 中的波浪号文本当成真实文件名。

未知 cwd 显示“目录未知”，不显示 `/`、`~` 或某个 SFTP 面板曾浏览的位置。已有旧值但重连／有效性不明时显示弱化的“待确认”状态，不允许借旧值立即导航。

## 4. 打开、搜索与选择

### 4.1 打开

1. 单击目录芯片；再次单击关闭。
2. 菜单锚定芯片上方、左对齐；空间不足时调整位置，避免窗口边界和其他浮层裁切。
3. 固定本次 `sessionId + connectionGeneration + cwdRevision`。浮层打开后如果聚焦切到别的终端，关闭菜单，绝不把旧条目转发给新终端。
4. 搜索框自动获得焦点。显示当前层列表；若暂无缓存，显示“正在读取目录…”。
5. 列表读取不执行 cd，不影响草稿，不改变 SFTP 浏览位置。

### 4.2 搜索

首期定义为**当前目录直接子目录名称的过滤**，不递归、不访问其他目录、不调用系统全局搜索。这样行为和性能都清楚，不会让 SSH 中的一次打字变成递归扫描。

- 首期建议不区分大小写的连续子串匹配，支持中文及 Unicode 原名；不修改真正路径的大小写或 Unicode 字节表示。
- 输入查询即时过滤已读取列表，不因每个按键重新请求远程目录。
- 同一固定排序用于空查询和过滤结果；建议按名称的自然排序。不要依赖文件系统返回顺序。
- 父目录项不参与名称匹配，在非根目录置顶保留。无匹配时仍能返回父目录，结果区显示“没有匹配的子目录”。
- 第一个匹配的**子目录**为默认活动项，与参考菜单默认高亮子目录的展示一致；无子目录时默认不选中父目录，避免用户空列表按 Enter 意外离开当前目录。
- 查询只存在于当前打开周期，关闭后清空。下次从实际 cwd 重新打开。
- 占位文案建议“搜索当前目录下的文件夹…”，比全局“搜索目录”更准确地交代范围。

隐藏目录：Warp 的默认规则尚未验证。建议默认隐藏点目录／平台 hidden 条目，并提供可发现的“显示隐藏目录”开关；精简首期若不做开关，必须在帮助文案中说明且记录为已知限制。不要自行排除 `node_modules`、`build`、`dist` 等正常目录。

### 4.3 目录列表

父目录行：上箭头 + `..（父目录）`，固定在搜索框下，普通结果区内部滚动；根目录不显示可执行的父目录项。

目录行：文件夹图标 + 名称。只列真正目录和已确认目标是目录的符号链接；不列普通文件、链接到文件、断链和类型未知的链接。保留路径原始名称，展示截断时使用 tooltip，执行时不使用截断文本。

名称超长／包含控制字符时，显示层将不可见字符可视化，不能破坏列表。首期命令注入拒绝含 NUL、CR、LF、ESC 等终端控制字符的目标路径；提示“该目录名称暂不支持快捷切换”，用户仍可自行在 shell 中处理。不能因“已正确引号转义”就忽略终端输入控制字符。

列表最大高约 240–260 CSS px，外层菜单随内容收缩。滚轮只滚结果列表，不滚终端历史，也不把方向键发送给终端。超过约 500 条时建议虚拟化；具体阈值在实现中用性能结果确定，不把大列表截断成“没有更多目录”。

### 4.4 选择子目录或父目录

**统一动作：提交一次目录切换，并关闭菜单。** 子目录即时切换关闭来自用户对 Warp 的确认；父目录采用相同动作是 Netcatty 的一致性选择。

```text
打开菜单 → 搜索 / 移动活动项 → 单击或 Enter
→ 校验会话与 shell 就绪状态 → 定向提交 cd → 关闭菜单
→ 芯片显示切换中，保留旧 cwd → 实际 cwd 回报 → 更新芯片
```

- 前置校验失败：不发命令，菜单保留并显示原因。
- 已提交但结果失败／超时：保持旧的确认值，显示可重试提示。再次打开时从实际 cwd 重新读取。
- 写入被接受不代表成功；chip 不立即乐观变成目标路径。
- 同一时间每个会话最多一个切换操作，防止双击写入两条 cd。
- 用户选择的是 symlink 时，shell 可能回报逻辑路径或物理路径。确认规则需要识别等价路径，不因回报真实目标路径就误报失败；不要为了检测而额外改变 `cd -L/-P` 策略。
- 用户在操作期间手动运行别的 cd 时，以最新实际回报为准；已经被更新事件取代的旧操作不能再弹出“切换成功”。

## 5. 键盘、焦点与草稿

| 按键／操作 | 菜单行为 |
| --- | --- |
| Tab / Shift+Tab | 依次进入／离开芯片；浮层内部遵循既有 Popover 焦点规则 |
| Enter / Space（芯片聚焦） | 打开菜单 |
| 普通文字 | 输入搜索词，支持输入法组合 |
| Up / Down | 移动活动项，必要时滚入可视区；建议到边缘停止而不循环 |
| Enter（菜单内） | 激活当前条目；无活动项时无操作 |
| Escape | 关闭，回到打开前的焦点位置 |
| 单击外部 | 关闭，不执行目录切换，不强行夺走外部目标焦点 |
| 单击条目 | 选择、定向提交并关闭 |

输入法组合期间 Enter 只结束组合，不触发 cd。方向键不能穿透到命令历史。不要首期抢占 Alt+Up、Cmd+K 等现有终端快捷键；如后续增加全局入口，要经过 Netcatty 快捷键配置体系。

撰写栏草稿必须保持文本、选择范围与光标位置。目录动作不调用“发送草稿”，不清空草稿，也不把 cd 塞进撰写栏输入框。成功关闭菜单后回到撰写栏，用户可继续编辑原命令。

**区分两类草稿**：撰写栏 textarea 内的草稿允许保留；真实 shell 提示符里已有半截输入时，首期拒绝自动注入。不能清空后恢复终端命令行，也不能把 `cd` 拼接到用户已有文字后面。

无障碍：芯片是可聚焦 button，包含“当前目录…，更改工作目录”的可访问名称和 expanded 状态。浮层使用搜索输入 + 可键盘操作的 listbox；活动条目通过 aria-activedescendant 或等价模式表达。不要把“当前活动目录项”错误描述为已经生效的 cwd。结果数量、读取失败与切换完成可温和播报，避免每个按键打断读屏。

## 6. 终端操作规则

目录选择是用户显式操作，首期无需额外“确认 cd”弹窗，但以下状态不能执行：

- 会话未连接、重连中、已关闭，或菜单绑定的连接代次已改变。
- 密码、MFA、sudo 提示或其他敏感输入状态。
- vim、less、top、REPL、持续运行命令或 alternate screen。
- 未能可靠判断 shell 正在空提示符等待命令；包含 shell 端已有输入。
- 只读／观察会话或 provider 未提供受控执行能力。
- 支持的 shell／路径转义策略未知。

不自动 Ctrl+C，不发送 Ctrl+U，不尝试退出 TUI，不把导航排到任意正在运行的进程后面。可以在这些状态下允许只读浏览菜单，但条目激活前必须再次校验，并给出“请等待终端回到空命令提示符”等具体原因。

一次选择固定目标终端，不读取全局“当前终端”作为异步完成时的目标；无论广播开关如何，只发给该会话。不会修改 Electron 主进程工作目录，不会更改同一主机上的其他终端，也不会修改新会话启动目录设置。

POSIX 命令建议使用绝对路径与集中转义，如 `cd -- '/home/me/project dir'`。路径内单引号使用已有转义辅助逻辑；绝不 `eval`，不拼 `ls | grep`，不将查询词解释为 shell 代码。PowerShell/CMD 需要独立策略，不能套用此命令模板。

命令可正常回显到终端，保留用户操作可理解性；Netcatty 撰写栏发送历史不应混入这类内部导航动作。shell 自身历史是否记录 cd 随 shell 正常规则，不承诺隐身。

## 7. 状态与反馈

| 状态 | 芯片 | 菜单／操作 |
| --- | --- | --- |
| cwd 未知 | “目录未知”弱化 | 提供刷新；没有可信 cwd 时不从 home 猜测列举 |
| 已知且空闲 | 路径、文件夹图标 | 可浏览、可选择 |
| 目录读取中 | 路径不变 | 搜索栏保留，结果区 loading；旧目录列表不能假装为新结果 |
| 空目录 | 路径不变 | 父目录 +“没有子目录” |
| 无搜索结果 | 路径不变 | 父目录 +“没有匹配的子目录” |
| 无读取权限 | 路径不变 | “无法读取此目录”，可重试；若可信父路径已知可尝试父目录 |
| shell 忙碌／敏感 | 路径仍可显示 | 只读浏览或禁用并给出原因，禁止注入 |
| 切换已提交 | 旧路径 + 小型进度提示 | 菜单关闭，暂禁重复提交 |
| 切换确认 | 最新 cwd | 更新路径，恢复可操作 |
| 切换失败 | 保留实际 cwd | 简短失败提示，点击可重新打开菜单 |
| 超时 | 保留最后确认值并标记待确认 | 建议等待 prompt 后刷新；不自动重发 cd |
| 会话切换／关闭 | 跟随新会话或移除 | 关闭旧菜单、取消结果应用 |

建议产品目标：有缓存时打开反馈在约 100ms 内；无缓存立即显示读取状态。目录读取超时与 cwd 确认超时分别设计，SSH 应允许更长等待。可建议从本地 3s、SSH 8s 的确认预算开始验证，但不是服务质量承诺；超时不能作为执行失败的唯一证据，也不能触发无条件重试。

## 8. 验收场景

| ID | 场景 | 预期 |
| --- | --- | --- |
| DIR-01 | 在 `~/git` 打开 | 显示该终端实际路径；菜单上方锚定，搜索获焦 |
| DIR-02 | 输入 `net` | 只过滤当前层匹配目录；不递归，不每键联网 |
| DIR-03 | 点击 Netcatty | 一次 cd 发给绑定会话；菜单关闭；真实 cwd 回报后更新 |
| DIR-04 | 点击父目录 | 定向切到父目录并关闭；根目录无有效父目录项 |
| DIR-05 | 目录数超过可视高度 | 内部滚动可达最后一项，搜索框不滚走 |
| DIR-06 | 空目录／无匹配 | 各自正确文案；不把空结果当读取失败 |
| DIR-07 | 有撰写栏草稿和选区 | 浏览、取消、切换均保留；导航不发送草稿 |
| DIR-08 | shell 内已有半条命令 | 不清空、不拼接、不注入；给出就绪提示 |
| DIR-09 | 命令运行中、TUI、密码／MFA | 所有情况下均无导航字节写入 |
| DIR-10 | 广播开启、多个终端／分屏 | 只切换选定会话，其余 cwd 和输入不变 |
| DIR-11 | 菜单读取时切换终端／重连 | 旧结果作废，旧条目不能对新会话执行 |
| DIR-12 | 读取失败、无权限、目标被删除 | 明确错误、可重试；保留实际 cwd |
| DIR-13 | 空格、单引号、中文、`$()`、反引号的目录 | 正确当作路径；不产生额外 shell 行为 |
| DIR-14 | 目录名包含换行或控制字符 | 拒绝快捷切换且解释；不写终端控制字节 |
| DIR-15 | 目录 symlink／断链／文件链接 | 目录链接可用，确认允许等价路径；其他不冒充目录 |
| DIR-16 | Enter 输入法组合与上下键 | 不误导航；事件不落到终端／历史 |
| DIR-17 | 快速双击或重复 Enter | 同一切换仅提交一次 |
| DIR-18 | 目标写入已接受但 cd 实际失败 | 不乐观展示目标；cwd 保持真实值 |
| DIR-19 | 普通 cd、脚本 cd、OSC 7 外部更新 | 芯片随真实 cwd 更新，不依赖仅从菜单触发 |
| DIR-20 | 不同主题、200% 缩放、窄分屏 | 可读、可聚焦、浮层不溢出、不遮掉全部输入区 |
| DIR-21 | SFTP 在别的目录 | 列表仍以终端 cwd 为准；不强制改 SFTP 的手动位置 |
| DIR-22 | SSH 额外通道受限／provider 无能力 | 明确不支持，不隐式新建登录到其他目标 |

## 9. 待确定的功能范围

1. 本地 POSIX 与普通 SSH POSIX 是否同批交付；建议先验证既有就绪 reader 和严格 cwd 回报，再决定。
2. 隐藏目录开关是否首期包含；推荐包含以便进入 `.config` 等常见目录。
3. 对只读会话采用禁用整个入口还是允许只读列举；推荐允许浏览、禁用激活并展示原因。
4. 最小高度 104px 与默认 144px 是否适合现有撰写栏；使用真实 UI 截图核定。

核心交互保持“单击目录即时切换并关闭”。
